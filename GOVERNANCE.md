# Governance

StreamCraft is maintained by **Maxime Rosito** ([@ROSITO](https://github.com/ROSITO)).

## Decisions

- Day-to-day merges: maintainer discretion after CI + review
- Architecture / ethics (DRM, auth): recorded in [`MEMORY.md`](MEMORY.md); PRD wins on product scope; ARCHITECTURE wins on module boundaries
- Breaking CLI JSON contract: requires a clear CHANGELOG note and preferably a minor/major version bump

## Becoming a maintainer

Consistent high-quality contributions and alignment with the ethics policy may lead to collaborator invitations. Contact via GitHub.

## Code of Conduct enforcement

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Reports go to the maintainer / GitHub moderation tools.
